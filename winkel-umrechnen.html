Rechnen mit Winkeln — Beispiele

① Winkel addieren
Wie groß ist die Summe von α = 75° und β = 50°?
  1. α + β = 75° + 50°
  2. = 125°
α + β = 125°
② Komplementwinkel (zu 90°)
Wie heißt der Komplementwinkel von α = 32°?
  1. β = 90° − α
  2. β = 90° − 32°
  3. = 58°
β = 58°
③ Supplementwinkel (zu 180°)
Wie heißt der Supplementwinkel von α = 110°?
  1. β = 180° − α
  2. β = 180° − 110°
  3. = 70°
β = 70°
④ Vollwinkel reduzieren (mod 360°)
Auf welchen Winkel im 1. Umlauf wird 850° reduziert?
  1. 850° − 360° = 490°
  2. 490° − 360° = 130°
850° entspricht 130°
⑤ Grad → Bogenmaß
Wandle 135° in Bogenmaß um.
  1. αrad = 135° · π/180
  2. = 135π/180
  3. = 3π/4
  4. ≈ 2.356
135° = 3π/4 ≈ 2.356 rad
⑥ Bogenmaß → Grad
Wandle 5π/6 rad in Grad um.
  1. α° = (5π/6) · 180/π
  2. = 5 · 180 / 6
  3. = 900 / 6
  4. = 150°
5π/6 rad = 150°
